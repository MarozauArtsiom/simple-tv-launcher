# Промпт для запуска всей работы одним сообщением

Скопируй текст ниже в новую сессию Claude Code для этого репозитория (облачную или локальную).

---

Ты продолжаешь проект Simple TV Launcher. Сделай всю работу из `docs/tasks.md` (T01–T27)
за этот запуск и не останавливайся на вопросы ко мне.

1. Сначала прочитай `CLAUDE.md`, `docs/sow.md`, `docs/tasks.md`, `docs/requirements.md`,
   `docs/ui-spec.md`, `docs/tech-stack.md`, `.claude/skills/README.md` и `docs/progress.md`.
   Начни с первой неотмеченной задачи в `docs/tasks.md`: если запуск прервётся, следующий
   продолжит с того же места.
2. Выполняй задачи строго по порядку. Перед каждой загружай скилы и читай документы из её
   пункта «Read».
3. После каждой задачи: гейт сборки и тестов зелёный → отметка в `docs/tasks.md` → строка в
   `docs/progress.md` → коммит. Пушь в рабочую ветку после каждого milestone (M0–M5).
4. Если что-то не решено, бери вариант по умолчанию из документов, запиши его в
   `docs/progress.md` в раздел «Decisions to review» и продолжай. Останавливаться можно, только
   если задачу сделать невозможно: тогда опиши блокер в `docs/progress.md` и переходи к
   следующей задаче, которая от неё не зависит.
5. Новые экраны (T06) рисуй мокапами и сразу реализуй. Запуск этого промпта и есть моё
   одобрение, рендеры я посмотрю после.
6. Android SDK в облаке ставь скриптом из T01, это разрешено. Если Maven Central или портал
   плагинов Gradle отвечают 429, повтори через паузу.
7. Каждый записанный скриншот (Roborazzi) открывай и сверяй с мокапом из `design/mockups/`.
8. Не нарушай принципы из `CLAUDE.md`: никакой рекламы и трекинга, ничего не работает в фоне,
   только стабильные версии библиотек, все тексты на шести языках.
9. Ответы мне пиши по-русски. Код, коммиты и документацию — на английском, кроме `README.md`
   (он на русском, это инструкция для меня).
10. В конце пришли короткий отчёт: что сделано, что не получилось и почему, размер release
    APK, где скачать debug APK из CI, список «Decisions to review» и что проверить на
    телевизоре (раздел «On the TV» в `docs/tasks.md`).
